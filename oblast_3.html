📘 Теоријски преглед и материјали

Линеарне једначине су једначине у којима је непозната на првом степену. Еквивалентне једначине имају исти скуп решења.

📐 Важне формуле

Линеарна једначина: a · x = b
Ако је a ≠ 0 ⇒ x = b / a (јединствено решење)
Ако је a = 0 и b = 0 ⇒ има бесконачно решења
Ако је a = 0 и b ≠ 0 ⇒ нема решења (немогућа)

📝 Поступно решени задаци за вежбање

Ниво 1

Задатак 1: Реши једначину $2x + 5 = 11$.

Поступак:

$2x = 11 - 5 \Rightarrow 2x = 6 \Rightarrow x = 3$.

Ниво 2

Задатак 4: Нађи решење неједначине $2x - 3 < 5$. Запиши највећи цео број који је решење.

Тачан одговор: 3

Поступак:

$2x < 8 \Rightarrow x < 4$. Највећи цео број мањи од 4 је 3.

Ниво 3

Задатак 5: За коју вредност параметра $k$ једначина $kx - 2 = 4$ има решење $x = 2$?

Тачан одговор: 3

Поступак:

$k(2) - 2 = 4 \Rightarrow 2k = 6 \Rightarrow k = 3$.
